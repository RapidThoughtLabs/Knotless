# NoteLess - Development Summary

## Project Overview

NoteLess is a cross-platform note-taking application built with Electron and Vite, featuring table-based notes with embedded NeDB storage. The application uses a frameless window design with platform-specific controls and a retro-minimalist gray aesthetic.

---

## What We've Built

### 1. Electron + Vite + NeDB Foundation

**Technology Stack:**
- **Electron** v28.1.0 - Desktop application framework
- **Vite** v5.0.11 - Fast development server and bundler
- **NeDB** - Embedded NoSQL database for data persistence
- **ES Modules** - Modern JavaScript module system

## TableNote Feature (Phase 1 Complete)

### Data Model

**NeDB JSON Schema:**
```javascript
{
  _id: String,              // Auto-generated by NeDB
  name: String,             // User-provided table name
  type: "recents" | "starred" | "archives",
  columns: Number,          // Number of columns (default: 3)
  data: [                   // 2D array of cell values
    ["cell1", "cell2", "cell3"],
    ["", "", ""]
  ],
  createdAt: Date,         // Auto-timestamped
  updatedAt: Date          // Auto-updated
}
```

**Database Location:**
- macOS: `~/Library/Application Support/noteless/tables.db`
- Windows: `%APPDATA%\noteless\tables.db`
- Linux: `~/.config/noteless/tables.db`

## Technical Challenges & Solutions

### Issue 1: Preload Script Import Error

**Problem:**
```
SyntaxError: Cannot use import statement outside a module
```

**Root Cause:**
Electron preload scripts don't support ES6 `import` syntax.

**Solution:**
Converted `preload.js` to CommonJS:
```javascript
// Before (ES6)
import { contextBridge, ipcRenderer } from 'electron';

// After (CommonJS)
const { contextBridge, ipcRenderer } = require('electron');
```

### Issue 2: Filter Type Mismatch

**Problem:**
Tables weren't appearing after creation, no console errors.

**Root Cause:**
- HTML filter buttons used `data-filter="recents"` (with 's')
- JavaScript used `type: 'recent'` and checked `currentFilter === 'recent'` (without 's')

**Solution:**
Changed all instances to use `'recents'`, `'starred'`, `'archives'` consistently.

### Issue 3: Traffic Light Overlay (Previous Issue)

**Problem:**
macOS traffic lights overlapping tabs, making them unclickable.

**Solution:**
- Dedicated safe area element
- Gray placeholder circles for unfocused state
- Z-index hierarchy management
- Flexbox layout for reliable spacing

## Development Notes

### Key Learnings

**Electron Preload Scripts:**
- Must use CommonJS (`require`), not ES6 (`import`)
- Bridge between main and renderer processes
- Run in isolated context for security

**NeDB Best Practices:**
- Initialize in main process
- Expose via IPC handlers
- Use promises for async operations
- Auto-timestamping with `timestampData: true`

**Filter Consistency:**
- Use consistent naming across HTML, CSS, and JS
- Watch for plural/singular mismatches
- Default filter should match default table type

**Modal Implementation:**
- Use fixed positioning with high z-index
- Blur backdrop for focus
- Multiple close methods (ESC, overlay click, cancel button)
- Auto-focus input on open

### Platform-Specific Considerations
- **macOS**: Traffic lights require ~80px safe area
- **Windows**: Custom controls require right-side space
- Always test window focus/blur states
