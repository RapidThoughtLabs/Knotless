# TableNote Implementation Plan

> **Goal:** Add editable table-based notes with NeDB persistence and filtering by type (recents/starred/archives)

---

## Data Model

### TableNote Schema (JSON in NeDB)

```javascript
{
  _id: String,              // Auto-generated by NeDB
  name: String,             // Table name (e.g., "Testing API 😊")
  type: "recent" | "starred" | "archived",  // For filtering
  columns: Number,          // Number of columns (default: 3, user-adjustable)
  data: [                   // Row data as array
    ["cell1", "cell2", "cell3"],  // Each row is an array of strings
    ["", "", ""],                 // Empty cells are empty strings
  ],
  createdAt: Date,          // For chronological sorting
  updatedAt: Date           // Last modification timestamp
}
```

## Implementation Order

1. **Install NeDB** - Add dependency
2. **Database Service** - Create `src/services/database.js` with CRUD
3. **Electron IPC** - Wire up database to preload/main
4. **TableNote Styles** - Add CSS for card, grid, footer
5. **HTML Template** - Add TableNote template to index.html
6. **Render Logic** - Implement `renderTables()` in main.js
7. **Create Handler** - Wire "+ add" button to create new table
8. **Cell Editing** - Contenteditable cells with auto-save
9. **Filtering** - Connect filter dropdown to filter tables

## Verification Plan

### Manual Testing (Primary)

Since this is an Electron app with embedded storage, manual testing is the primary verification method:

1. **Start the app:**
   ```bash
   npm run electron:dev
   ```

2. **Test table creation:**
   - Click "+ add" button
   - Verify new table appears in content area
   - Verify table has default 3 columns and empty rows

3. **Test cell editing:**
   - Click on a cell, type content
   - Click away, verify content persists
   - Close and reopen app, verify data is still there

4. **Test row auto-add:**
   - Type in the last row of a table
   - Verify a new empty row is added automatically

5. **Test filtering:**
   - Create multiple tables
   - Change filter to "starred" - verify "recent" tables are hidden
   - Change filter to "archives" - verify only archived tables show

6. **Test data persistence:**
   - Close app completely
   - Reopen app
   - Verify all tables and data are preserved

> [!NOTE]
> The 3-dot options popup (for starring, archiving, deleting) will be implemented in Phase 2.
